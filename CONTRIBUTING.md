# Contributing to Interview Questions Dataset

Thank you for your interest in contributing to this interview questions repository! We welcome contributions from everyone.

## 📋 How to Contribute

### Adding New Questions

1. **Fork the repository** and create a new branch for your contribution
2. **Choose the appropriate category** for your question
3. **Follow the question format** (see below)
4. **Submit a Pull Request** with a clear description of your additions

### Question Format

Each question should follow this structure:

```markdown
## Question Title

**Difficulty:** [Easy/Medium/Hard]

**Topic:** [Specific topic within the category]

### Problem Statement

[Clear and concise description of the problem or question]

### Example (if applicable)

[Provide examples with input/output]

### Solution Approach

[High-level approach to solving the problem]

### Code Solution (if applicable)

```language
// Code solution with comments
```

### Time & Space Complexity

- **Time Complexity:** O(?)
- **Space Complexity:** O(?)

### Follow-up Questions

[Optional follow-up questions to extend the discussion]

### Tags

`[tag1]` `[tag2]` `[tag3]`
```

## 🎯 Guidelines

### Quality Standards

- **Clarity:** Questions should be clear and unambiguous
- **Relevance:** Questions should be relevant to real interviews
- **Accuracy:** Solutions should be correct and well-explained
- **Completeness:** Include all necessary information

### Naming Conventions

- Use descriptive file names: `two-sum-problem.md`, `reverse-linked-list.md`
- Use lowercase with hyphens for file names
- Group related questions in subdirectories when appropriate

### Content Guidelines

- **Be Respectful:** Maintain a professional and inclusive tone
- **No Duplicates:** Check if a similar question already exists
- **Provide Context:** Explain why the question is important
- **Credit Sources:** If adapting from another source, provide attribution

## 🔍 Review Process

1. Submit your Pull Request
2. Maintainers will review your contribution
3. Address any feedback or requested changes
4. Once approved, your contribution will be merged

## 💡 What to Contribute

- New interview questions
- Improved solutions to existing questions
- Better explanations or examples
- Corrections to errors or typos
- Additional test cases
- Documentation improvements

## 🚫 What Not to Contribute

- Questions copied directly from active interview pools without permission
- Inappropriate or offensive content
- Low-quality or incomplete questions
- Duplicate content

## 📞 Getting Help

If you have questions about contributing, please:
- Open an issue for discussion
- Check existing issues for similar questions
- Review this guide and the README

## 🙏 Recognition

All contributors will be recognized in the project. Thank you for helping make this a valuable resource for the community!
