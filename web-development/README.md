# Web Development Interview Questions

This directory contains web development interview questions covering frontend, backend, and full-stack topics.

## Topics

- **HTML/CSS** - Semantic HTML, flexbox, grid, responsive design
- **JavaScript** - DOM manipulation, frameworks, state management
- **Frontend Frameworks** - React, Vue, Angular
- **Backend** - REST APIs, authentication, middleware
- **HTTP** - Methods, status codes, headers
- **Security** - XSS, CSRF, authentication
- **Performance** - Optimization, caching, lazy loading
