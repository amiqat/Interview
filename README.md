## Question Format

Each question follows a consistent structure:

- **Question** — The interview question.
- **Hint** — What to look for in a strong answer.
- **🚩 Red Signal** — Warning signs of a weak or dangerous answer.

## How to Use

1. Pick categories relevant to the role.
2. Start with foundational questions, then progress to deeper ones.
3. Use **Hints** to guide follow-up discussion.
4. Watch for **🚩 Red Signals** — these indicate gaps that may be hard to remediate on the job.
