# Interview Questions Dataset

A comprehensive collection of interview questions across various topics and difficulty levels. This repository serves as a resource for both interviewers and candidates preparing for technical interviews.

## 📚 Categories

This repository is organized into the following categories:

- **[Algorithms](./algorithms/)** - Data structures, sorting, searching, and algorithm design questions
- **[System Design](./system-design/)** - Architecture, scalability, and system design interview questions
- **[Behavioral](./behavioral/)** - Soft skills and behavioral interview questions
- **[Database](./database/)** - SQL, NoSQL, and database design questions
- **[Programming Languages](./programming-languages/)** - Language-specific questions (Python, Java, JavaScript, etc.)
- **[Web Development](./web-development/)** - Frontend, backend, and full-stack web development questions
- **[DevOps](./devops/)** - CI/CD, containerization, cloud services, and infrastructure questions

## 🚀 Getting Started

1. Browse through the categories above
2. Each category contains multiple question files organized by topic
3. Questions are formatted with:
   - Problem statement
   - Difficulty level
   - Expected answer/solution approach
   - Time/Space complexity (for technical questions)

## 📖 How to Use This Repository

**For Interviewers:**
- Use questions to assess candidates during interviews
- Customize questions based on the role and seniority level
- Refer to provided solutions and evaluation criteria

**For Candidates:**
- Practice questions to prepare for interviews
- Study solution approaches and best practices
- Use difficulty levels to gauge your progress

## ⭐ Features

- Well-organized categorization
- Multiple difficulty levels (Easy, Medium, Hard)
- Detailed solutions and explanations
- Real-world interview questions from top companies
- Regular updates with new questions
