# Behavioral Interview Questions

This directory contains behavioral and soft skills interview questions.

## Topics

- **Leadership** - Leading teams, mentoring, decision making
- **Teamwork** - Collaboration, conflict resolution, communication
- **Problem Solving** - Analytical thinking, creativity, debugging
- **Work Ethic** - Time management, prioritization, meeting deadlines
- **Adaptability** - Handling change, learning new technologies
- **Career Goals** - Motivation, growth, long-term vision

## Question Categories

1. **Tell Me About a Time** - Past experience questions
2. **Situational** - Hypothetical scenario questions
3. **Self-Assessment** - Strengths, weaknesses, interests
