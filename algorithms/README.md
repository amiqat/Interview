# Algorithms Interview Questions

This directory contains algorithm-related interview questions covering various topics.

## Topics

- **Arrays & Strings** - Questions about array manipulation, string processing
- **Linked Lists** - Singly linked lists, doubly linked lists, circular lists
- **Trees & Graphs** - Binary trees, BSTs, graph traversal, shortest paths
- **Sorting & Searching** - Various sorting algorithms, binary search, search optimization
- **Dynamic Programming** - Memoization, tabulation, optimization problems
- **Recursion & Backtracking** - Recursive solutions, backtracking algorithms
- **Hash Tables** - Hash maps, hash sets, collision resolution
- **Stacks & Queues** - Stack operations, queue operations, priority queues
- **Heaps** - Min heaps, max heaps, heap operations

## Difficulty Levels

- 🟢 **Easy** - Fundamental concepts, basic implementations
- 🟡 **Medium** - More complex algorithms, optimization required
- 🔴 **Hard** - Advanced algorithms, multiple concepts combined
