# System Design Interview Questions

This directory contains system design interview questions for building scalable systems.

## Topics

- **Scalability** - Horizontal scaling, vertical scaling, load balancing
- **Databases** - SQL vs NoSQL, sharding, replication
- **Caching** - Cache strategies, CDN, distributed caching
- **Message Queues** - Async processing, pub/sub patterns
- **Microservices** - Service architecture, API design
- **Distributed Systems** - CAP theorem, consistency, availability
- **Cloud Services** - AWS, Azure, GCP components

## Difficulty Levels

- 🟡 **Medium** - Standard system design problems
- 🔴 **Hard** - Complex distributed systems, high-scale requirements
