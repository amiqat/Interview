# REST API, Swagger & Authentication

This category covers RESTful API design, OpenAPI/Swagger documentation, authentication and authorization patterns, and security considerations for modern .NET APIs. Questions focus on real-world scenarios including endpoint design reviews, versioning strategies for public APIs, JWT validation, machine-to-machine auth flows, and common security pitfalls like CORS misconfiguration. These topics are essential for any developer building or consuming HTTP APIs in a production environment.
