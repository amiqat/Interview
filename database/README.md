# Database Interview Questions

This directory contains database-related interview questions covering SQL, NoSQL, and database design.

## Topics

- **SQL Queries** - SELECT, JOIN, aggregations, subqueries
- **Database Design** - Normalization, schema design, relationships
- **Indexing** - Index types, performance optimization
- **Transactions** - ACID properties, isolation levels
- **NoSQL** - MongoDB, Redis, Cassandra, DynamoDB
- **Performance** - Query optimization, explain plans
- **Replication & Sharding** - Data distribution, consistency

## Difficulty Levels

- 🟢 **Easy** - Basic SQL queries, fundamental concepts
- 🟡 **Medium** - Complex queries, optimization, design
- 🔴 **Hard** - Advanced optimization, distributed databases
